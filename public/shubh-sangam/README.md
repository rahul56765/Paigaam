# Shubh Sangam frontend integration

The renderer in `templates/shubh-sangam/render.js` exports `render(paigaam, opts)` and resolves customer data through the sibling config and schema. See `templates/shubh-sangam/README.md` and `templates/shubh-sangam/INTEGRATION.md` for the data contract, validation limits and integration status. The template is registered in this checkout; deployment and end-to-end behavior still require verification.

The couple, parents, additional family, optional individual portraits and venue photograph are editable. The single wedding date and time supply the visible weekday, date, time/muhurat and countdown; `timing: wedding` events use the same instant. Events can inherit the wedding venue or use an independent location. Photo gallery and event photos use bfday upload references. The map link is allowlisted or generated as a search for the effective location.

RSVP requires a phone number with `+`, an international calling code and a plausible length. This is only a format check; the number and WhatsApp availability must be verified by the customer. Without it the page says online RSVP is unavailable. The demo supplies no number. Guests review and send their WhatsApp response themselves; this template does not save it. Optional background audio starts only on a guest gesture.

The opening ceremony, Haldi, Sangeet and mandap illustrations are local WebP artwork, with all invitation text rendered separately as editable HTML. Event artwork follows the event name rather than list position; uploaded event photos remain visible below the illustration. The text-free floral envelope and gold seal are layered over the opening art. Missing or corrupt artwork is restored on family startup from the checksummed `assets/shubh-sangam` pack. `thumbnail.webp` is a smaller copy of the opening art, and the config points to `/shubh-sangam/thumbnail.webp` for the catalog. The devotional garment illustration is the intro fallback. The sample names and location live in the config, not the frontend artwork. The requested sample address has not been independently verified.
