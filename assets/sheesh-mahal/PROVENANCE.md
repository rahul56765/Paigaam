# Original generated scene artwork

All seven visual source images were generated in Hyperagent on 25 October 2026 for this invitation. No image was extracted from the Instagram creator's template. The reference informs the sunset-palace / vintage-car / emerald / moonlit narrative, not ownership of the original vendor's designs.

- sunset: Nano Banana Pro, original imaginary Rajasthan palace, 16:9, 2K. Canonical environment reference.
- night: Nano Banana 2.1, matching imagined palace at blue hour, using sunset as reference.
- car: Nano Banana 2.1, teal Ambassador rear-three-quarter wedding prop, using sunset for lighting reference. Anonymous illustrative occupants, not customer likenesses.
- arch: Nano Banana 2.1, isolated floral/brass arch using sunset for colour reference.
- flowers: Nano Banana 2.1, isolated jasmine/rose cascade.
- marble: Nano Banana 2.1, emerald marble material scan.
- stone: Nano Banana 2.1, carved sandstone material scan.

The generated magenta isolation mats were removed computationally into actual RGBA alpha. All images were resized and WebP encoded. The manifest records final bytes and SHA256 checksums; .webp.b64 files are deployment inputs and public copies are restored at boot. The renderer adds live text; there are no baked customer names or logos.
