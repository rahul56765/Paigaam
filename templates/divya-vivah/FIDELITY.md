# Reference fidelity

## Preserved
- Supplied divine-hands film, re-encoded for lighter web playback; no new generated film.
- Exact initial Marathi Unicode wording as manually transcribed from the supplied JPG; editable customer copy, not generated lettering.
- 2:3 portrait invitation proportions; tiny Ganesh at top, pale diagonal divine hands, burgundy type, Maharashtrian seated couple, floral and ceremonial bottom illustration.

## Not pixel-identical
- User supplied no layered source, text-free background or original font. A text-free restoration was generated from the JPG; small illustrative details differ. It is not the untouched original illustration.
- Fonts are OFL Tiro Devanagari Marathi and Amita, chosen by visual comparison. The original custom name lettering and decorative calligraphic swashes are not exactly reproduced.
- Scalable HTML positioning closely follows the image, not identical glyph metrics at every pixel. Long customer copy shrinks within fixed artwork regions.
- Third screen is a new matching countdown and venue layout, not part of the original image.
- Page one includes a hand/tap icon and the actual film poster. It is not a new custom photograph of a hand.

## Verification boundaries
- Supplied audio remains in the film; it is started by guest action and faded before the card appears. No extra background song is shipped.
- Source asset reuse was raised with the user; they replied “Go ahead”. No independent artwork ownership/license provenance was supplied.
- Marathi source was visually transcribed; no native-speaker proofreading was available. Customer/owner should approve wording, names, real date and venue pin before selling/sharing.
- This is an interactive webpage invitation, not an exported three-slide MP4. Countdown and Maps require the webpage.
